# Virtual Transcript

Define a platform-neutral Virtual Transcript contract and shared conformance fixtures, replace react-virtuoso with a Phoenix-owned web virtualizer covering finalized history, streaming tail, dynamic measurement, prefix continuity, deep links, and follow-tail, and validate current Chrome, Safari, and Firefox behavior. The replacement should become the sole production implementation without a long-lived adapter flag. Preserve exact scroll-command ownership and the existing long-conversation performance gains.
