Implement the inline terminal: typing `!` as the first character of the conversation composer opens a PTY-backed terminal (reusing the specs/terminal stack) scoped to the conversation. Each OSC-133-delimited command is committed to conversation history as a user-originated `bash`-run tool round (Track B shared history), visible to a later agent turn. A started-but-uncompleted command (C without D) is committed as an interrupted round when superseded by the next command or by session close — never dropped. Opening is gated to an idle conversation; the conversation is busy while the session is live and returns to idle on close without any agent turn. See specs/inline-terminal/ (requirements.md, executive.md, inline-terminal.allium) and the rationale in specs/adrs/004_inline-terminal-shared-history-per-command.md. Includes the bedrock coordination point: a new `inline_terminal` core_status variant joined to is_busy (deferred BedrockInlineTerminalBusyState).
