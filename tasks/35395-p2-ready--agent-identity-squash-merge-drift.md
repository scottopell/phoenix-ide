The agent-identity spec describes task completion as squash-merge to main (citing the deprecated REQ-PROJ-009): requirements.md:15 ("on task completion they are squash-merged") and design.md:95 ("the squash commit on main is authored by the user"). That merge model is deprecated. The live model is push-branch + user-merges-via-PR (work-lifecycle REQ-WL-002); Phoenix never squash-merges to base. The agent-identity rationale (agent commit trailers get squashed away; user re-signs the squash commit) assumes a squash that no longer happens. Review whether the commit-trailer / signing semantics still hold under the push-branch model and update agent-identity to the current merge model. Discovered during the work-actions-bar spec reorg; deliberately not fixed there to avoid rewriting agent-identity's technical model blind.
