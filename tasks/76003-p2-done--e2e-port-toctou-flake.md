tests/e2e/run.py picks its server port via _free_port() (bind :0, read port, close), then phoenix-ide binds it later — a TOCTOU race. Observed during a full ./dev.py check --all: "Error: Os { code: 48, kind: AddrInUse }" at server startup while prod phoenix + dev servers were running; immediate re-run passed. Fix by retrying server startup on AddrInUse with a fresh port (bounded retries), or have phoenix-ide bind :0 itself and report the actual port (e.g. print/file the bound port for the harness to read).
