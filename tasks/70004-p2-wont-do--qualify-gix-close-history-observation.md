# Qualify gix for Close's read-only Git history observation

## Observed journey and invariant

A normally created Git-backed conversation can detach through ordinary Git use and then Close through the real provider path. A preserved checkout may retire into History; an at-risk history inventory or uncertain observation must keep the target intact. This is a separate simplification of the observer, not a repair of the installed rc.20 flow or a release gate. Owning contracts: `specs/work-lifecycle/requirements.md` (especially REQ-WL-002/002a) and `specs/work-lifecycle/work-lifecycle.allium`.

## Final disposition — retired, not shipped

The user selected **“Retire migration”** (decision question `55a71a35-1c9b-46a9-a311-99b7928bca3a`). [PR #1194](https://github.com/scottopell/phoenix-ide/pull/1194) was closed without merge. Keep Phoenix's existing descriptor capture and endpoint parser, and its bounded Git CLI HEAD and reachability checks. No production dependency, backend, policy, or installed service changed. No real-provider parity run was performed. This decision applies only to the gix migration; native Close and lifecycle simplification remain independent.

- **Real captured bytes:** the exact hosted run confirmed decoder root equality on descriptor-captured SHA-1 and SHA-256 linked-worktree reflogs. Separately, synthetic blank and unterminated records with isolated old-only and new-only roots produced byte-identical unsorted Git CLI inventories, including the exact-stash case. The inventory check did not use the captured bytes and did not exercise production fingerprinting or mutation-time revalidation.
- **Reflog compatibility:** `gix-ref::LineRef` rejected `<old> <new> \n` and `<old> <new> opaque tail\n`, from which Phoenix currently extracts both endpoints. This is observed behavior to preserve under a parity-only commission, not an established user requirement. A fallback would retain the parser the migration was meant to remove.
- **Minimal dependency alternative:** `gix-hash` matched tested decoder rows, but replaced only hexadecimal and width checks, not endpoint framing, spelling, null handling, or limits. The isolated hosted build added 29 external packages and 86,296 binary bytes and took 6.82 s vs 0.34 s for the baseline; these are standalone measurements, not Phoenix workspace deltas.
- **Typed HEAD:** gix classified `HEAD → refs/tags/absent` as unborn where Phoenix rejected it. A wrapper could fix that discrepancy with branch-only and exact-absence checks; repeated observation and cancellable repository I/O would still need qualification. The observed mismatch is not a categorical limitation of gix.
