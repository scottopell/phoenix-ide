# Clean build artifacts in live Phoenix worktrees

A normal Rust test compile failed with `No space left on device` while writing `target/debug/incremental/.../query-cache.bin`. The host had only 198 MiB free; measured live Phoenix worktrees retained target trees of 44.4 GB, 25.1 GB, 16.7 GB, and 13.2 GB. Existing `/about` cleanup safely handles leftover worktrees but intentionally cannot remove live worktrees, so users need a typed, explicit action to clean generated build artifacts from a selected live worktree without deleting source, branch, uncommitted work, or runtime-owned state. Define strict allowed generated paths, reject active compiler/check ownership, report estimated/reclaimed bytes, and integrate with existing disk drilldown rather than adding automatic deletion policy.
