The tmux probe regression deadline_kills_and_reaps_probe_child assumes its shell fixture writes probe.pid before a 500 ms deadline. On a heavily loaded macOS host it fails at the PID-file read with NotFound even when cleanup correctly killed the child before that write. It passed alone and failed again in the six-test tmux::probe::tests module while qualifying PR #793. Replace the timing-dependent PID-file witness with a causal parent-observed child identity/readiness boundary, preserving the assertion that timeout kills and reaps the child.
