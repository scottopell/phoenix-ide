# Port the active-PR rail interaction to desktop conversations

Replace the hard-to-reach desktop PR selector and wrapped Work Actions presentation with a desktop-adapted active-PR rail. Show actionable PR identity, branch/status, and feedback indicators persistently; expand the selected PR into one hero action plus semantically grouped supporting actions. Keep StateBar selection only as a fallback when the rail is unavailable, preserve WorkDisposition and active-PR authority, and add deterministic desktop QA fixtures plus browser validation.
