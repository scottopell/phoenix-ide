## Phoenix v0.13.0

### What’s new

- **Continuous conversation history.** Browse older transcript pages, follow links to historical conversations, and return without losing your reading position. Continue working while keeping the same conversation identity. ([#932](https://github.com/scottopell/phoenix-ide/pull/932))
- **Clearer conversations and evidence.** Compact event cards, expandable provenance and typed internal citations make activity easier to follow. Scroll, layout and table-rendering fixes improve reading long conversations. ([#918](https://github.com/scottopell/phoenix-ide/pull/918), [#890](https://github.com/scottopell/phoenix-ide/pull/890), [#933](https://github.com/scottopell/phoenix-ide/pull/933), [#940](https://github.com/scottopell/phoenix-ide/pull/940))
- **A persistent home for Global.** The Global Coordinator now has its own WorkScope and home. Delegated work shows task/model context, and WorkScope resource views show tracked process usage. ([#910](https://github.com/scottopell/phoenix-ide/pull/910), [#950](https://github.com/scottopell/phoenix-ide/pull/950), [#888](https://github.com/scottopell/phoenix-ide/pull/888))
- **Standalone browser tools and macOS apps.** Use `phoenix-browser` from another coding harness without running the Phoenix server, or download the Apple Silicon or Intel Phoenix.app ZIP. [Browser guide](https://github.com/scottopell/phoenix-ide/blob/v0.13.0/docs/phoenix-browser.md).

### Behavior and compatibility changes

- **Conversation names and links:** conversations have one editable human name, and duplicate names are allowed. Readable links are separate from permanent conversation identities; former slugs are not guaranteed to redirect. ([#951](https://github.com/scottopell/phoenix-ide/pull/951))
- **API clients:** conversation creation is asynchronous. Wait for an accepted request to become ready before using the conversation. ([#916](https://github.com/scottopell/phoenix-ide/pull/916))
- **Gateway configuration:** use `PHOENIX_LLM_REQUEST_MODELS` for request-model overrides. Gateways that require a `provider` header must configure it through `LLM_CUSTOM_HEADERS`; automatic inference was removed. The native Codex bridge is unaffected. ([#875](https://github.com/scottopell/phoenix-ide/pull/875))
- **Durable wakes:** durable wake execution was removed; historical records remain available. ([#894](https://github.com/scottopell/phoenix-ide/pull/894))
- **Browser CLI updates:** close existing CLI sessions before replacing the binary.
- **Managed launchd updates:** the existing helper rejects the schema128→129 upgrade interval. This is a limitation of that helper, not a general restriction on v0.13. See the [engineering release record](https://github.com/scottopell/phoenix-ide/pull/962#issuecomment-6280860417) for details.
