## Phoenix v0.13.0-rc.2

This is a **public prerelease**, not the latest stable release. It targets macOS desktop, browser, and standalone server use; native iOS/TestFlight and federation are not release gates for this candidate. Publishing these artifacts does not deploy or upgrade any production host.

## Highlights since RC1

- **Canonical conversation links:** `/c/` navigation follows the durable conversation while exact historical transcript/tool references remain available as evidence. (#862)
- **Safer Close:** retirement uses a single normal attempt, preserves uncertain or unique work for an explicit decision, and distinguishes ended conversations from cleanup failures. Failure alerts retain trusted sender provenance. (#871, #866)
- **Bounded tool waits and provider recovery:** tool-wait settlement is bounded; transient model-capacity recovery preserves overload identity, retry timing, and accepted input. Structurally empty Astra assistant turns are classified explicitly rather than treated as successful answers. (#873, #797, #880, #877)
- **Bounded predecessor recall:** historical context is retrieved in bounded pages rather than relying on an unbounded handoff. (#775)
- **Mobile comfort:** touch-selection reactions dock away from native selection controls, and the installed-PWA top safe area is isolated. (#795, #878)

## Verification and acceptance limits

The release workflow rebuilds this version from its immutable tagged source. Both macOS architectures must pass Developer ID signing, hardened-runtime verification, Apple notarization, stapling, Gatekeeper, embedded-helper byte equality, and native isolated signed-helper startup/authentication/database/graceful-stop checks before publication. The private release's exact eight payloads plus `SHA256SUMS` must verify before it becomes public. Sanitized headless receipts are separate Actions artifacts, not extra release payloads.

**Known acceptance gaps remain pending; publication does not mean they passed:**

- The user-deferred **macOS GUI/clean-host desktop pass** has not been performed.
- The user-deferred **phone-access, physical iPhone Safari, and installed-PWA pass** has not been performed.
- Native headless checks do not establish real-provider, GUI, or published updater end-to-end acceptance. Earlier candidate core-journey and disposable managed-helper-cycle evidence belongs to its original source/bytes; it is not new RC2-byte acceptance or a universal install/update/rollback guarantee.
- The original stuck-tool-wait incident's root cause is not established merely by the bounded-settlement fix. A reported small-scroll jump remains a separate reproduction item, not a claimed fix.

## Upgrading

- **Back up before upgrading.** Startup migrations run forward. An older runtime is not guaranteed to read a migrated database; database rollback requires stopping Phoenix and restoring a matching backup with the older runtime.
- Stable-only update discovery is unchanged. This RC does not enable prerelease update offers or replace the latest stable release.
- Final promotion requires a new stable version and freshly built/verified artifacts; RC bytes are not relabeled and existing tags are not moved.
- macOS archives are direct-distribution ZIPs, not a Mac App Store package, DMG, installer, or desktop updater.
