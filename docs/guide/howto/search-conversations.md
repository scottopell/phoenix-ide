# Search conversations

Jump to any past [conversation](../concepts/conversations.md) without scrolling
the sidebar — the command palette searches them as you type.

## Before you start

You're on desktop (the command palette is desktop-only).

## Steps

1. **Open the command palette** with `Ctrl/Cmd+P`.
2. **Type.** It searches your conversations as you go — the input reads **Search
   conversations…** (or **Search conversations and files…** when you're in a
   conversation). Results group by source, each showing the conversation's slug
   and directory.
3. **Pick one.** `↑` / `↓` to move, `Enter` to open.

## Result

The selected conversation opens. (Type `>` first to run a command instead of
searching — see the [command palette reference](../reference/command-palette.md).)
