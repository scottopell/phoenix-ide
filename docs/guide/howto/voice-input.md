# Voice input

Speak your message instead of typing it. Phoenix transcribes into the composer,
where you can edit before sending.

## Before you start

A browser with Web Speech support (Chrome). The microphone button only appears
when your browser supports it — there's nothing to enable.

## Steps

1. **Click the microphone** in the composer (**Start voice input**). Grant
   microphone permission if asked.
2. **Speak.** The button switches to **Stop recording** and your words stream
   into the input live as you talk.
3. **Stop** by clicking again or pressing `Esc`. Phoenix finishes transcribing
   (**Processing speech…**) and drops the text into the composer, appended to any
   draft already there.
4. **Review and send.** Edit the transcript like normal text, then send.

## Result

Your spoken message in the composer, indistinguishable from typed text — image
attachments and existing draft text are preserved.

## Troubleshooting

- **No microphone button.** Your browser lacks Web Speech support — use Chrome.
- **Permission error.** Allow microphone access for the site, then **Retry**.
