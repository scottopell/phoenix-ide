# patch

> **At a glance:** the agent edits files by exact-match replacement (plus append,
> prepend, overwrite). Multiple edits in one call apply **all-or-nothing**.

## What it does

Edits a file by matching existing text exactly and substituting new text, or by
adding to / replacing the whole file. On a near-miss the agent's match is retried
with fuzzy adjustments (dedent, trimmed lines) before failing.

## Operations

| Op | Does |
|----|------|
| `replace` | swap `oldText` for `newText` — `oldText` must occur **exactly once** |
| `append_eof` | add text at end of file |
| `prepend_bof` | add text at start of file |
| `overwrite` | replace the whole file (creates it if missing) |

## What you'll see

A unified diff per patch in the transcript; an autogenerated-file warning if the
target looks generated.

## Limits & gotchas

- **60 KB** input per call.
- **Atomic:** several patches in one call apply against the original together — if
  any fails, none apply.
- **`replace` needs a unique match** — ambiguous `oldText` is rejected.
- **Read-only in Explore:** patch is restricted to the `tasks/` directory so the
  agent can draft a plan; real edits wait for [Work mode](../../concepts/modes.md).
  Explore sub-agents have no patch at all.
