# Keyboard shortcuts

> **At a glance:** press `?` anywhere in Phoenix to open this list. Keys adapt to
> your platform (e.g. `Ctrl` shows as `⌘` on macOS).

## Global

| Key | Action |
|-----|--------|
| `Ctrl+P` | Command palette |
| `?` | Toggle the shortcut help panel |
| `Escape` | Close panel / navigate back |

## Conversation

| Key | Action |
|-----|--------|
| `/` | Focus the message input |
| `Enter` | Send message |
| `Shift+Enter` | New line |

## Sidebar

| Key | Action |
|-----|--------|
| `Up / Down` | Navigate conversations |
| `Enter` | Open conversation |
| `n` | New conversation |

## Question panel

| Key | Action |
|-----|--------|
| `Up / Down` | Move between options |
| `Enter` | Select option |
| `Space` | Select / toggle option |
| `Tab` | Next question |
| `Shift+Tab` | Previous question |
| `n` | Add notes (preview questions) |
| `Ctrl+Enter` | Submit answers |
| `Escape` | Dismiss the question (with confirmation) |
